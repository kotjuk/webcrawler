# Webcrawler
Консольное и веб-приложение на Go для поиска информации на сайтах. Программа получает стартовые ссылки из DuckDuckGo, обходит связанные страницы на заданной глубине, строит инвертированный индекс «слово → URL» в памяти и показывает страницы, где встречаются слова из запроса.

## Функционал
- Получение до **12 ссылок** из HTML-выдачи DuckDuckGo по поисковому запросу
- Обход сайтов с настраиваемой **глубиной** (от 1 до 10, по умолчанию 2)
- Извлечение текста из тега `<body>`, разбиение на слова и построение индекса
- Локальный поиск: для каждого слова из запроса выводятся URL страниц, где оно встречалось (без дублей)
- **Консольный режим** — ввод запроса и глубины в терминале
- **Веб-интерфейс** — форма в браузере с полями «запрос» и «глубина обхода»
- Подсчёт обработанных страниц и запись посещений в лог

## Требования
- [Go](https://go.dev/dl/) 1.23 или новее
- Доступ в интернет (запросы к DuckDuckGo и обход сайтов)

## Установка и сборка
Клонирование репозитория:
git clone https://github.com/kotjuk/webcrawler.git
cd webcrawler

Установка зависимостей:
go mod download

Сборка исполняемого файла (Windows):
go build -o webcrawler.exe .

## Инструкция по использованию
### Консольный режим
go run .
Программа запросит:
1. **Поисковый запрос** — фраза для DuckDuckGo и для последующего поиска по индексу
2. **Глубину обхода** — число от 1 до 10 (Enter = 2)
После обхода в консоль выводятся найденные URL и статистика по числу страниц.

### Веб-интерфейс
go run . --web
Откройте в браузере: `http://localhost:8080`
На странице укажите запрос и глубину обхода, нажмите «Запустить». Отобразятся seed-ссылки, результаты поиска и количество обработанных страниц.

## Модули и методы
### `main`

| Функция | Описание |
|---------|----------|
| `main()` | Инициализация логгера, разбор флагов, запуск CLI или веб-режима |
| `runCLI()` | Интерактивный ввод запроса и глубины, обход, вывод результатов |
| `runWeb(addr)` | HTTP-сервер: форма `/`, обработка POST `/run` |
| `searchInIndex(idx, query)` | Поиск по всем словам запроса с объединением URL без дублей |

### `search`

| Функция | Описание |
|---------|----------|
| `GetLinks(query string) ([]string, error)` | POST на DuckDuckGo HTML, парсинг до 12 ссылок `a.result__a` |

### `crawler`

| Тип / функция | Описание |
|---------------|----------|
| `Options` | Параметры обхода (`MaxDepth`) |
| `Options.normalized()` | Проверка глубины (1–10, по умолчанию 2) |
| `Crawl(startURL, idx, mon, opts) error` | Обход сайта: ссылки, индексация `body`, логирование |

### `index`

| Тип / функция | Описание |
|---------------|----------|
| `Index` | `map[слово]map[url]struct{}` с `RWMutex` |
| `New() *Index` | Создание пустого индекса |
| `Add(words []string, url string)` | Добавление слов страницы (в нижнем регистре) |
| `Search(query string) []string` | URL для одного слова (точное совпадение ключа) |

### `monitor`

| Функция | Описание |
|---------|----------|
| `New() *Monitor` | Создание счётчика |
| `IncrementPages()` | +1 к числу проиндексированных страниц |
| `Pages() int` | Текущее количество страниц |
| `Report()` | Вывод статистики в консоль |

### `logger`

| Функция | Описание |
|---------|----------|
| `Init()` | Открытие/создание `crawler.log` |
| `Log(message string)` | Запись строки с датой и временем |

## Как работает поиск (кратко)
1. Запрос отправляется в DuckDuckGo → до 12 HTTP-ссылок.
2. Для каждой ссылки запускается `Crawl` с заданной глубиной.
3. Текст страниц попадает в индекс.
4. По словам из запроса из индекса собираются URL результатов.

## Ограничения
- Индекс только в памяти — при перезапуске данные теряются
- Поиск по отдельным словам, без ранжирования и стемминга
- Зависимость от разметки DuckDuckGo (`a.result__a`)
- Нет ограничения домена, rate limit и таймаутов HTTP
- Обход может занимать много времени при большой глубине и многих ссылках
